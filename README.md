# The Heavenly Bodies of Garrison, NY

An interactive star map made for Dad's birthday, September 2026.

## Put it on GitHub Pages

1. Create a new repository on GitHub (for example `night-sky`).
2. Upload everything in this folder (`index.html`, `favicon.ico`, `apple-touch-icon.png`, `icon-512.png`, this README) to the repository.
3. In the repository, go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, and save.
4. After a minute or two the site is live at `https://<your-username>.github.io/night-sky/`.

## Changing the words

All of the text lives in one block near the bottom of `index.html` that starts with `const COPY = {`.
Edit anything in quotes and commit. Words in `{curly braces}` fill in automatically, so leave those.
